# Jacobian Estimation via JVP Sampling

This module provides a dedicated pathway for estimating Jacobians in Mamba models using JVP (Jacobian-Vector Product) sampling techniques.

## Overview

The Jacobian estimation functionality allows you to:
- Compute Jacobian samples for Mamba/Mamba2 models
- Analyze sensitivity of model outputs to weight perturbations
- Generate visualization data for Hessian approximations
- Support research into quantization-aware training and GPTQ optimization

This is a **completely separate pathway** from the evaluation pipeline (`eval.sh`), providing a clean interface specifically for Jacobian analysis.

## Quick Start

### Basic Usage

```bash
# Run Jacobian estimation on a Mamba2 model
./scripts/submission_scripts/jvp_jacobian_estimation.sh state-spaces/mamba2-130m
```

### Advanced Usage

```bash
# Customize parameters
./scripts/submission_scripts/jvp_jacobian_estimation.sh state-spaces/mamba2-2.7b \
    --w_bits 4 \
    --nsamples 256 \
    --seqlen 1024 \
    --output_dir ./my_jacobian_results \
    --group_heads \
    --verbose
```

## Command-Line Options

| Option | Description | Default |
|--------|-------------|---------|
| `model_path` | Path to the model (required) | - |
| `--w_bits N` | Target bit-width for weights | 4 |
| `--nsamples N` | Number of calibration samples | 128 |
| `--seqlen N` | Sequence length for calibration | 1024 |
| `--output_dir PATH` | Output directory for results | `./jacobian_jvp_error` |
| `--pretrained_dir PATH` | Directory containing pretrained models | `./pretrained_models` |
| `--group_heads` | Group heads during reordering (for mamba2) | false |
| `--verbose` | Enable verbose logging | false |

## Python API

You can also use the module directly in Python:

```python
from jacobian_estimation import save_jacobian_samples
from utils import build_mamba_and_tokenizer, set_deterministic

# Set up deterministic behavior
set_deterministic(seed=1234)

# Load model
model, tokenizer, _ = build_mamba_and_tokenizer(args, model_type="mamba2")

# Run Jacobian estimation
try:
    save_jacobian_samples(
        model=model,
        tokenizer=tokenizer,
        device="cuda",
        w_bits=4,
        model_type="mamba2",
        nsamples=128,
        seqlen=1024,
        output_dir="./my_results"
    )
except ValueError as e:
    if "Jacobian loop over" in str(e):
        print("Jacobian estimation completed successfully!")
```

## How It Works

1. **Calibration Data**: Loads calibration samples from WikiText-2 dataset
2. **Layer-wise Processing**: Iterates through each layer of the model
3. **Hook Registration**: Registers forward hooks to capture intermediate activations
4. **JVP Computation**: Uses the SMGPTQ class to compute Jacobian-Vector Products
5. **Data Persistence**: Saves Jacobian samples and timing information to disk
6. **Visualization**: Generates plots showing Hessian approximation quality

## Technical Details

### MambaJacobianEstimator (formerly SMGPTQ)

The core of the Jacobian estimation uses the `MambaJacobianEstimator` class, which:
- Captures inputs and outputs from each mixer layer
- Computes Jacobian-Vector Products using forward-mode autodiff
- Approximates the Hessian matrix as `J^TJ` (Gauss-Newton approximation)
- Supports various probe sampling strategies

**Note**: The old name `SMGPTQ` is maintained as an alias for backward compatibility.

### Supported Models

Currently supports:
- ✅ Mamba (state-spaces/mamba-*)
- ✅ Mamba2 (state-spaces/mamba2-*)
- ❌ Other model types (GLA, DeltaNet, etc.) - not yet implemented

## Differences from Evaluation Pipeline

| Feature | Jacobian Estimation | Evaluation Pipeline |

| **Purpose** | Analyze Jacobians for quantization research | Evaluate model performance |
| **Entry Point** | `jacobian_estimation/main_jacobian.py` | `main.py` |
| **Shell Script** | `jvp_jacobian_estimation.sh` | `eval.sh` |
| **Output** | Jacobian samples, plots, timing data | Accuracy metrics, perplexity |
| **Dependencies** | SMGPTQ, JVP computation | lm-eval-harness |
| **Use Case** | Research, GPTQ optimization | Model validation, benchmarking |

## Notes

- The function raises `ValueError("Jacobian loop over!")` upon successful completion (this is expected behavior)
- Ensure sufficient GPU memory for large models
- Processing time scales with model size and number of samples
- Results are compatible with the existing visualization pipeline
